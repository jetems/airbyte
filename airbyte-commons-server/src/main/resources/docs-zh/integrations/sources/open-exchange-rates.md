# Open Exchange Rates

> 本文档由 jetems 基于官方英文设置指南翻译（模型润色），技术标识符、命令与配置字段名请保持原文。

**Open Exchange Rates** 源连接器用于从 Open Exchange Rates 拉取数据并同步到目标端。

## 设置指南

1. 在 Airbyte 中打开「源」→「+ 新建源」
2. 选择 **Open Exchange Rates** 并输入名称
3. 按配置表填写认证信息（API Key / OAuth / 连接串 / 账号密码等）
4. 按需设置起始日期、资源范围、区域等可选项
5. 点击「设置源」完成检测并保存

## IP 白名单

若使用 Airbyte Cloud 且组织限制访问 IP，请将 [Airbyte Cloud IP 地址](https://docs.airbyte.com/platform/operating-airbyte/ip-allowlist) 加入白名单。
